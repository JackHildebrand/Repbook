# Repbook

Mobile-first personal strength tracker.

## Features
- Log workouts with sets, weight and reps
- Build reusable routines
- Exercise library and personal records
- Workout history and progress summary
- Import Hevy CSV exports
- JSON backup and restore
- Installable PWA with offline caching
- Local-first browser storage

## Run
Open `index.html` or serve the folder with `python3 -m http.server 8000`.

## Deploy
Static app; no build step. Compatible with GitHub Pages or Netlify.

This is a recreation of the earlier Repbook app, not an export of its original source.
